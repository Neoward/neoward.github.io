2. Das Spiel NEOWARD

NEOWARD erhebt keine personenbezogenen Daten und überträgt nichts an mich oder an Dritte. Das Spiel enthält keine Werbung, keine Analyse- oder Tracking-Dienste und keine Benutzerkonten.

Auf deinem Gerät speichert das Spiel: Spielstand und Fortschritt, Einstellungen, Kalibrierwerte der Waffen, einen Zwischenspeicher für Grafik (Shader) und eine kurze technische Absturzspur.

Zwei Funktionen der Meta-Plattform nutzt das Spiel, beide laufen über Meta und nicht über mich:

  • Lizenzprüfung: Beim Start fragt das Spiel über das Meta Platform SDK, ob dein Meta-Konto das Spiel besitzt. Dafür ist die Internet-Berechtigung der App gesetzt; das Spiel selbst baut keine weiteren Verbindungen auf.
  • Cloud-Sicherung: Ist in deiner Quest die Cloud-Sicherung eingeschaltet, sichert Meta den Spielstand und die Einstellungen in deinem Meta-Konto (ohne Grafik-Zwischenspeicher und Protokolle). Diese Sicherung bleibt nach dem Deinstallieren erhalten, bis du sie in den Einstellungen der Quest löschst. Ohne Cloud-Sicherung bleiben alle Dateien auf dem Gerät und werden beim Deinstallieren gelöscht.

Kameras, Mikrofon und Raumdaten der Brille nutzt das Spiel nicht. Die Bewegungen von Kopf und Controllern werden nur zur Darstellung im Spiel verarbeitet und nicht gespeichert.

2. The game NEOWARD

NEOWARD does not collect personal data and transmits nothing to me or to third parties. The game contains no advertising, no analytics or tracking services and no user accounts.

On your device the game stores: save game and progress, settings, weapon calibration values, a graphics cache (shaders) and a short technical crash trace.

The game uses two features of the Meta platform; both are handled by Meta, not by me:

  • License check: At start the game asks the Meta Platform SDK whether your Meta account owns the game. The app holds the internet permission for this; the game itself opens no other connections.
  • Cloud backup: If cloud backup is enabled on your Quest, Meta backs up the save game and settings to your Meta account (without graphics cache and logs). This backup remains after uninstalling until you delete it in the Quest settings. Without cloud backup all files stay on the device and are deleted when the game is uninstalled.

The game does not use the headset's cameras, microphone or room data. Head and controller movement is processed only for rendering and is not stored.
